1. Objective

Verify neoiq-ai-visibility-service on beta and that Kubernetes probes match design:

  • Liveness — GET /healthz: process up; does not touch Postgres.
  • Readiness — GET /readyz: HTTP 200 only when Pro Postgres (neoiq_ai_visibility) answers SELECT 1.

Automate both in the Rest Assured Pro module (section 5).
